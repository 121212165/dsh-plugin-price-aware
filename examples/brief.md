# 角色
你是一名资深插件开发工程师兼技术调研员，擅长前端动效、音频集成与开发者工具生态。

# 任务目标
为一个名为 "DeepSeek Harness" 的 AI 应用开发「自然环境沉浸」插件：
AI 生成内容期间，屏蔽默认的流式打字机输出，改用自然风景动画 + 环境音效过渡，
生成完成后一次性呈现完整结果；支持用户上传自定义图片作为等待画面。

# 第一步：资料核实与调研（必须先完成）
1. 联网检索 "DeepSeek Harness" 的官方仓库、文档、插件机制：插件如何注册、
   如何拦截流式响应/token 渲染事件、UI 注入点位置、配置持久化方式、安装分发方式。
2. 收集同类实践：浏览器扩展或 AI 客户端插件中「替换流式渲染」的成熟实现思路与代码示例。
⚠️ 诚实性要求：若检索不到该项目的可核实资料，请直接说明"暂无官方文档可供验证"，
禁止虚构 API 名称与代码签名；此时改按通用 Chrome 扩展 Manifest V3 结构继续，
并在产出中显式标注所有待验证点。

# 第二步：功能规格
F1 流式输出屏蔽：拦截逐 token 渲染，内容后台缓存；生成期间仅显示环境动画覆盖层；完成后一次性淡入全文；提供「恢复原生流式」全局开关与快捷键。
F2 自然环境动画：内置 ≥3 个场景（晨雾森林、溪流山谷、雨夜窗景），带环境动态感（摇曳树叶、水波、雨滴粒子），用 CSS 动画 / Canvas / 循环视频之一实现，标签页不可见时自动暂停。
F3 环境音效：场景配套环境音（鸟鸣、流水、雨声），仅用免版权(CC0)音源；音量滑块 + 一键静音；遵守浏览器自动播放策略，用户首次交互后再启动音频。
F4 自定义图片：设置面板支持上传 jpg/png/webp/gif（可选短视频）；图片仅存本地、绝不上传服务器，隐私说明写入文档；提供裁剪/铺满/高斯模糊三种填充模式和亮度遮罩调节。

# 第三步：工程要求
- 文件结构遵循第一步查到的插件规范；查不到则按 Manifest V3 组织；
- 性能：动画走 requestAnimationFrame 与合成层，不阻塞主线程；
- 无障碍与降级：适配 prefers-reduced-motion，插件出错时静默回退原生界面。
